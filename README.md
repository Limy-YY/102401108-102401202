# 校园失物招领平台

## 项目简介

### 项目背景

本项目旨在开发一个**校园失物招领平台**，解决**校园失物信息分散、查找不便**的问题，帮助师生集中发布寻物/招领信息、按分类浏览、按关键词与条件搜索、查看物品详情与联系方式，提升失物招领的效率。

### 技术栈说明

| 项目 | 说明 |
|---|---|
| 前端技术 | HTML / CSS / JavaScript |
| 前端框架 | uni-app + Vue 3 |
| 运行平台 | Android 手机端 App（APK 安装，数据保存在手机本地） |

## APP 功能概览

- **登录 / 注册**：使用学号与密码登录，新用户可注册账号。
- **发布信息**：发布「寻物」或「招领」，附物品名称、地点、时间、图片与描述。
- **集中浏览**：首页按「全部 / 寻物 / 招领」分类浏览，最新发布排最前。
- **搜索信息**：按关键词搜索，并可叠加类型 / 时间 / 地点筛选。
- **查看详情与联系**：查看物品完整信息，获取发布者的微信号 / 手机号。
- **标记完成**：物品找回或归还后，可标记「已找到 / 已归还」。
- **编辑资料**：管理头像、昵称、微信号、手机号。

## 使用说明

### 运行步骤

1. 在 GitHub 仓库的 **Releases** 页面下载 `.apk` 安装包。
2. 将安装包传到 Android 手机并安装（若提示「未知来源」，需先在系统设置中允许）。
3. 打开 App，使用演示账号登录：学号 `20240001`、密码 `campus2024`（首次打开已内置示例数据）。

### 功能操作指南

1. **登录**：输入学号和密码登录；新用户点「注册」填写信息创建账号。

2. **浏览首页**：登录后进入首页，顶部为搜索栏，中部为「全部 / 寻物 / 招领」分类 Tab，下方按发布时间倒序展示物品卡片，底部为「首页 / 发布 / 我的」导航。

3. **发布信息**：点底部「发布」，选择类型（寻物 / 招领），填写物品名称、场所、位置、日期时间（必填），以及颜色、图片、描述（选填），点「发布」即可。

4. **搜索信息**：在首页搜索栏输入关键词进入搜索页，支持多个关键词（空格分隔），并按类型 / 时间 / 地点筛选；无结果时显示空状态提示。

5. **查看详情与联系**：点任意卡片进入详情页，查看物品图片、名称、类型、状态、场所、时间、颜色与描述，以及发布者的微信号 / 手机号（可一键复制）。

6. **更新状态**：本人发布的物品详情页底部可「标记为已找到 / 已归还」，也可「编辑」或「删除」；标记后可「重新寻物 / 招领」恢复。

##  附加特点说明

1. **类型 / 时间 / 地点三维筛选**：搜索时可组合筛选，快速定位「大概在哪、什么时候丢的」物品。
2. **一键复制联系方式**：详情页微信号、手机号旁各有一键复制按钮，联系发布者更方便。
3. **多关键词 + 智能排序**：多个关键词需全部命中，名称命中多者靠前、已完成信息沉底，结果更精准。
4. **完成态保留可浏览**：标记「已找到 / 已归还」后信息不删除，仍可查看但沉底、角标更新，减少无效联系，并保留记录方便后续有需要重发的场景。
